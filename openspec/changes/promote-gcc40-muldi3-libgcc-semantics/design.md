## Context

`bootstrap/gcc-4.0.ncl` currently builds a GCC-4.0-shaped pass1 bridge and deterministic `libgcc.a`. `_negdi2` is the first semantic member; `_muldi3` is still generated by the placeholder branch even though the archived correctness roadmap names it as the next useful promotion.

## Goals / Non-Goals

**Goals:**
- Promote exactly `_muldi3` to a real signed 64-bit multiplication body.
- Preserve deterministic ar(5) archive construction and existing `_negdi2` semantics.
- Verify with the smallest artifact and host-linked semantic smoke.

**Non-Goals:**
- Do not replace the full libgcc2 implementation.
- Do not change GCC driver, `cc1`, generator, or native compiler behavior.
- Do not claim full GCC 4.0 correctness.

## Decisions

### 1. One arithmetic member only

**Choice:** Implement `_muldi3(long long lhs, long long rhs) { return lhs * rhs; }` behind the existing per-member generation branch.

**Rationale:** `_muldi3` is a bounded, independently smoke-testable follow-up to `_negdi2` and exercises a different arithmetic operation without introducing division edge cases.

**Alternative:** Promote division or shifts first. Rejected for this slice because they carry more edge-case semantics and can follow after multiplication proves a second semantic member.

**Implementation:** Add a `_muldi3` branch adjacent to `_negdi2`; leave other members as placeholders.

## Risks / Trade-offs

**Host smoke only** → The first proof links the built archive with the host compiler, not the GCC pass1 driver. This is acceptable for the member-body semantic slice because the artifact under test is the produced object/archive.

**Signed overflow ambiguity** → Smoke cases must avoid overflow and focus on representative positive, negative, and zero products.

## Validation Plan

- `./target/debug/crunch eval bootstrap/gcc-4.0.ncl` plus `/bin/sh -n` on the generated builder.
- `./target/debug/crunch build bootstrap/gcc-4.0.ncl --store "$PWD/.crunch-drain/store" -j 4 --trust-unsigned --no-substitute`.
- Inspect `libgcc.a` with host `ar`/`nm` and link a `_muldi3` semantic smoke.
- `openspec validate promote-gcc40-muldi3-libgcc-semantics --strict` and `openspec validate --all --strict` before archive.
