## Cutover

`main.rs` no longer reads the clock before receipt dispatch. Each of the four receipt operations plans the `ReadClock` effect and its own read/store/write/readback effects before the first clock access. Private shell-local `ReceiptBundlePort` methods retain the original CLI error classification; typed observations are classified before the terminal report. Export reads its published bundle back and compares complete contents, and import re-reads the persisted bundle, reconciled semantic graph, and embedded attestation sidecars before announcing success. Verify and list classify their actual validated read/verification results. If verify or import uses `--archive`, a separate conditional `ReadFiles` effect invokes the concrete streaming archive reader before the store-backed verification/import; the planned expected store prefix is compared against the independently parsed archive header, and a failed archive read skips the later store effect. No `--archive` means no invented read. A failed step classifies its failure and remaining skipped effects rather than silently completing.

`wasm-component build` plans Nickel/stdlib reads, process execution, evidence writes, and a separately bounded 64 MiB report read before preparation. One concrete pipeline port executes the inseparable tools/publication; independently re-read report bytes determine the publication and readback observations. Successful reports additionally run the existing materialization and sidecar verifier. A blocked report remains printable with its original nonzero exit only after classifying the process and publication as failed; a missing, oversized, divergent, or invalid publication cannot report success.
