## Lessons this session paid for

- `--option substituters ''` also disables `cache.nixos.org`: a garbage-collected
  crates.io vendor derivation then rebuilds and fails with HTTP 403.
- Never `git stash pop` without reading `git stash list` first. On a clean tree
  the push silently does nothing and the pop applies someone else's older stash;
  the entry survives a failed pop, so recover with `git reset`,
  `git checkout -- <path>`, and `rm -rf` of the restored untracked directory.
- Refreshing the durable publication receipt after a lock change needs **two**
  files: `evidence/radicle/durable-file-publication-adoption-v1.ncl` (the record)
  and `lib/durable-file-publication-adoption-receipt.ncl` (the validator's
  expectations). A half-refresh fails as `adoption-cargo` drift.
- `RunError`'s display adds a human prefix, so assert `.contains(...)` on message
  text rather than equality on the rendering.
- Measure untyped core errors with ast-grep, not grep: a line pattern counts
  nested generics such as `Result<(Map<String, String>, Vec<Warn>), Error>`. The
  checker rule reads whole signatures, so it is stricter than the AST pass and
  found three sites the measurement had missed.
- `cargo check --workspace --all-targets` did not reach the profile the
  `release-determinism-quality` check compiles; run the failing Nix attribute
  itself after a fix.
- Test-only type errors surface only when tests compile; build the affected test
  targets explicitly.
- Tiger Style bites on new code: 2+ assertions per function, ≤70-line functions,
  predicate names for booleans, no tautological assertions, typed request
  structs instead of bool pairs, and a reservation (`Vec::with_capacity` or a
  counted bound) before any loop that grows a collection.
