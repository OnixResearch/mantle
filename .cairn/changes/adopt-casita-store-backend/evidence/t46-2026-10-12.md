A trusted upstream source-tree/NAR identity or repaired Nix fetch provenance is prerequisite to resolving this default-shell blocker. `flake.nix:1758-1765` already arranges an immutable Crane patched source map for the shell hook, but that hook did not run here because shell construction failed first.

Blindly adding a workspace-local replacement pointing at existing `vendor-deps/` would override the shell's Cargo-home Crane mapping and adopt a closure that currently fails byte-for-byte generator comparison. That is **not** an integrity-preserving fix in this dirty shared checkout. T4.6 remains open pending an accepted vendor closure and a verified usable default Nix shell; the scoped patched Cargo checks above are bounded evidence, not substitution for the acceptance gates.
