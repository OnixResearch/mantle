### Emit valid typed words in generated Rust invocations (P1)

`src/source_built_rust_programs_minicargo.rs:738-739` constructs `--cfg` feature operands with `lit(format!("feature=\"{feature}\""))`; its `lit` helper yields `WordPart::Literal`. Current produced requests contain four slash-bearing cfg values, including `feature="regex-syntax/default"` and `feature="valuable?/std"`. `src/source_built_rust_programs_successors_profile.rs:18-25,92-95` also adds `-Clink-args=-Wl,-rpath,$ORIGIN/../lib` through `lit`. The successor author serializes these arguments unchanged into a `WriteText`-produced request (`source_built_rust_programs_successors.rs:620-647`); the minicargo translator similarly copies existing arguments/environment into a serialized invocation (`source_built_rust_programs_translation.rs:291-332`). Its `input()` helper preserves a supplied path verbatim, so the traced request members containing `./` and `../` also reach the decoder unchanged.

The frozen consumer is correct to reject these encodings: `source_built_recipe.rs:1110-1117` rejects slash, backslash, or NUL in ordinary `Literal`; `relative()` at 555-565 rejects non-normalized `Input.path`; and `decode_invocation()` applies those same checks to the produced request at 1551-1552. Runtime `CommandOperands::invocation()` calls that decoder at `source_built_recipe_exec.rs:285-299`; `RecipeExecution::step` returns on a decode error before calling `launch` at 897-930. Thus these are not merely advisory lexical concerns: the produced Exec cannot run. The request trace found 2,931 literal-path violations (2,927 rpath operands plus four cfg operands) and 12 noncanonical Input members (`./` or `../` components), all attached to 2,933 exact Produced Text request inputs with immediate unguarded Exec consumers (0 guarded consumers). The existing strict admission contract must remain; the producer needs to distinguish literal data from paths and normalize source members before authoring the Input word.

Parent's saved baseline reproduction metadata is `parent-word-inspection/reproduction-pueue26.json` (Pueue 26, `Failed: 101`); its log is `parent-word-inspection/reproduce-profile-admission-before.log`. The isolated frozen-source test `original_rpath_profile_survives_strict_deferred_invocation_admission` reports `FAILED`, 0 passed/1 failed, and the exact error `Build("source recipe: untyped filesystem path in literal command word for step profile.compile")` at `source_built_rust_programs_successors_profile_tests.rs:72:102`.
