# Drain evidence: add-nix-remote-service-gateway

Date: 2026-09-03

## Scope

This change adds a bounded Nix daemon-store adapter and a versioned asynchronous Build API. The adapters reuse Mantle's existing coordinator, lease, fencing, transfer, log, CAS, PathInfo, store, and signing-key boundaries.

The implementation does not add an evaluator, scheduler, store of truth, source fetcher, command shell, or administration shortcut.

## Reviewed implementation

- `crates/crunch-build/src/distributed/remote_gateway.rs` owns pure admission, capability, bounds, idempotency, reconnect, cursor, completion, evidence, and Valence-mapping decisions.
- `src/remote_gateway.rs` owns Nix protocol I/O, bounded stdio, store calls, NAR verification, trusted PathInfo keys, operator status, and CLI routing.
- `src/remote_gateway_api.rs` owns bounded Build API input, verifier-file matching, secret FD handling, coordinator calls, durable public/internal linkage, cancellation, pagination, completion signing, and private atomic state.
- Vendored `nix-compat` now supports explicit byte-value, collection, aggregate-message, and framed-payload limits. Gateway strict mode disables compatibility stubs that return synthetic empty results.
- `lib/remote-builders.ncl` and `src/remote_farm_config.rs` carry private-by-default typed policy.
- `tests/fixtures/onixos-remote-farm/` is a compatibility-only OnixOS fixture.

## Security review outcomes

The drain review found and fixed these issues before completion:

1. Completion events now retain submission-time policy identity. Reconnect-time policy cannot rewrite it.
2. Persisted public attempt identities, request and policy digests, internal job linkage, completion identities, sequences, and signature names are validated before reuse.
3. Cursor keys use zeroizing owners on every return path.
4. Duplicate idempotency conflicts are decided before coordinator mutation.
5. Nix collection lengths, aggregate metadata, byte values, and NAR frames are rejected before unbounded allocation.
6. The supported Nix range is protocol 1.23 through 1.37. Older `STDERR_READ` framing is excluded.
7. Generic `query-referrers` and `query-realisation` stubs are disabled for the gateway.
8. Selected lower message and cursor limits are enforced, not only global ceilings.
9. Authority and policy JSON inputs require regular no-follow files.
10. API authority matching and pure planning run before cursor or signing-key access.
11. Untrusted JSON parse failures return stable errors without echoing secret-looking field names.
12. Gateway evidence carries a `RecordedOnly` mapping to `valence.build-service-evidence.v1`. It is an assembly input, not a complete Valence bundle.
